How it’s engineered

  1. 01
    Never a blank page
    Live data comes from the TMDB API; if it fails, the site falls back to local data and still renders every section.
  2. 02
    One accent variable for the whole UI
    Every highlight reads --movie-accent, so a page can re-colour itself without touching components.
  3. 03
    Two languages, two themes
    EN / RU and light / dark, remembered in the browser. No UI kit — plain CSS and GSAP.
  4. 04
    Bugs found and fixed
    Header vanishing on navigation; a 726 px overflow on 375 px phones (flex children without min-width: 0).
